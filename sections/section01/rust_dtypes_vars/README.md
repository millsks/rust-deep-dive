# rust_dtypes_vars

Practice with Rust variables, mutability, shadowing, and basic data types.

## What this project covers

- Immutable vs mutable variables (`let` vs `let mut`)
- Variable shadowing
- Primitive data types (`i32`, `u64`, `f64`, `bool`, `char`)
- String types (`&str` and `String`)

## Run

```bash
cargo run
```

## Build

```bash
cargo build
```
