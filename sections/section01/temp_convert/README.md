# temp_convert

An interactive temperature converter CLI.

## What this project covers

- Unit conversion between Celsius, Fahrenheit, and Kelvin
- Parsing flexible unit input (for example: `C`, `CELSIUS`, `FAHR`, `KELVIN`)
- Input validation and error handling
- Looping user interaction until exit

## Run

```bash
cargo run
```

Then enter values like:

- `100 C`
- `212 F`
- `373 K`
- `exit` to quit

## Build

```bash
cargo build
```
